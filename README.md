# 🌐 Network Topology Simulator

A Python-based desktop application for visualizing computer network topologies through an interactive graphical user interface built with Tkinter.

The project helps students understand different network structures, including Star, Bus, Ring, and Mesh topologies, through visual representations of connected computers.

---

## 📌 Overview

The **Network Topology Simulator** is an educational application developed using Python and Tkinter. It allows users to explore different network topologies, add or remove computers, and visualize how devices are connected within a network.

The project demonstrates basic computer networking concepts along with Python GUI development.

## ✨ Features

- 🌟 **Multiple Network Topologies:** Supports Star, Bus, Ring, and Mesh topologies.
- ➕ **Add Computers:** Dynamically add computers to the network.
- ➖ **Remove Computers:** Remove computers from the network.
- 🎨 **Interactive GUI:** Simple, modern desktop interface.
- 🔗 **Visual Connections:** View connections between computers.
- 📚 **Educational Purpose:** Helps students understand fundamental networking concepts.
- 🖥️ **Desktop Application:** Runs locally using Python.

## 🔗 Supported Network Topologies

### ⭐ 1. Star Topology
All computers connect to a central node. This arrangement is easy to manage and commonly used in local area networks.

### 🚌 2. Bus Topology
All computers connect to a shared communication backbone.

### 🔄 3. Ring Topology
Computers connect in a circular structure, with each computer linked to neighboring computers.

### 🌐 4. Mesh Topology
Computers connect to multiple other computers, providing alternative paths between network devices.
